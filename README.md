# Panduan Edit Portofolio PKL (Wildan Darius Permana)

1. Ekstrak file ZIP ini ke folder di laptop/PC.
2. Masukkan foto ke dalam folder `img`:
   - `img/profil.jpeg` -> Foto profil utama & foto kecil di bagian Ringkasan Data.
   - `img/proyek1.jpeg` -> Foto dokumentasi Proyek 1.
   - `img/proyek2.jpeg` -> Foto dokumentasi Proyek 2.
   - `img/proyek3.jpeg` -> Foto dokumentasi Proyek 3 (opsional; tampilkan placeholder jika belum tersedia).
3. Buka folder di VS Code, buka `index.html`, lalu ganti teks di dalam tanda `[...]` (seperti nama sekolah, kelas, dan nomor WA/Email).
